# 🔍 Tech Gap Checker

> 写代码之前，先把你项目里藏着的技术盲区全部扫出来。

---

## 这是什么

一个 AI Coding 的 Skill。在 AI 动手写代码之前，自动做一轮全局技术扫描，把"你没提、但你项目必须有的东西"列出来。

---

## 为什么需要

你跟 AI 说完项目需求，AI 开始写代码——但它只做你明确说的部分。

你说"我要一个投票页面"，它给你一个投票页面。它不会主动告诉你：投票数据存哪儿？刷新会不会丢？多个人同时投怎么同步？部署到哪儿别人能访问？

**AI 不会主动填补你的知识盲区。这个 Skill 会。**

---

## 它扫什么

八个维度，全覆盖：

| 维度 | 会追问的问题 |
|------|-------------|
| 👥 多人交互 | 需要各自操作还是同屏？需要房间/组队吗？需要实时同步吗？ |
| 💾 数据存储 | 用户数据存哪儿？刷新会丢吗？需要数据库还是文件就够了？ |
| 🔐 用户系统 | 怎么区分不同用户？需要登录还是昵称就行？权限怎么管？ |
| 📡 实时通信 | 一个人操作，其他人需要立刻看到吗？ |
| 🚀 部署托管 | 前端放哪儿？需要后端吗？免费额度够吗？环境变量怎么管？ |
| 🧩 第三方服务 | 需要数据库服务吗？需要支付吗？需要图床吗？需要 AI API 吗？ |
| 🛡️ 安全边界 | 用户输入会不会被注入？需要限流吗？敏感数据怎么处理？ |
| 📱 移动端 | 手机能用吗？需要触屏适配吗？横竖屏怎么处理？ |

每个维度输出三种标记：
- ✅ 你提到了
- ⚠️ 你没提但项目需要
- ❌ 不适用（说明理由）

最后给出一份**推荐技术选型**，标注免费额度，直接能用。

---

## 输出长什么样

```
📋 技术零件清单
✅ 前端框架：React（你提了）
✅ 托管平台：Vercel（你提了）
⚠️ 数据库：需要持久化存储（盲区）
⚠️ 认证系统：需要区分不同用户（盲区）
⚠️ 文件存储：用户上传图片需要图床（盲区）
❌ 支付系统：当前版本不需要
❌ 实时通信：纯展示类项目，不需要

🔑 最关键盲区（Top 3）
1. 数据库 — 用户内容刷新就没了
2. 用户认证 — 不知道谁发了什么
3. 图床 — 用户上传的图需要有地方存

🛠️ 推荐方案：Vercel + Supabase（免费层 500MB 数据库 + 文件存储），你的体量完全够
```

## 安装

### Codex

```bash
git clone https://github.com/kenanguo/tech-gap-checker.git /tmp/tech-gap-checker
mkdir -p ~/.agents/skills/tech-gap-checker
cp /tmp/tech-gap-checker/SKILL.md ~/.agents/skills/tech-gap-checker/
```

在 `~/.codex/AGENTS.md` 路由规则中加一行：

```
新项目启动：优先 `tech-gap-checker`，写代码前扫描技术盲区。
```

### Claude Code

```bash
git clone https://github.com/kenanguo/tech-gap-checker.git /tmp/tech-gap-checker
mkdir -p ~/.claude/skills/tech-gap-checker
cp /tmp/tech-gap-checker/SKILL.md ~/.claude/skills/tech-gap-checker/
```

在 `~/.claude/CLAUDE.md` 路由规则中加一行同上。

配好之后，每次你说"帮我建一个 XX"，AI 会自动先跑扫描再写代码。不想自动路由的话，对 AI 说一句 **"跑 tech-gap-checker"** 也能手动触发。

---

## 适用谁

- 你懂产品、懂业务，但不懂后端/运维/安全
- 你让 AI 建过项目，结果发现总是在补"没想到的东西"
- 你不想每次跟 AI 说需求都像写技术规格书一样面面俱到
